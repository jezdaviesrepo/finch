By difficulty

Every link was checked against the data. A link is a key when each row on the parent side is unique and at least 95% of child rows find their parent. Only keys are declared as foreign keys in Snowflake. Links come from FINCH’s SQLite files, from joins the gold SQL uses, or were found in the data: a column named like another table’s key whose values all appear there.
